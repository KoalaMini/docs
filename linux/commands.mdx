# 1. 文件与目录操作

<AccordionGroup>
  <Accordion title="ls (list) — 列出目录内容">
    ```bash
    ls                # 列出当前目录文件
    ls -l             # -l = --long，长格式（权限、大小、时间）
    ls -a             # -a = --all，显示隐藏文件（以 . 开头）
    ls -h             # -h = --human-readable，文件大小友好显示（K/M/G）
    ls -t             # -t 按修改 time 排序
    ls -S             # -S 按文件 Size 排序
    ls -lh            # 组合：长格式 + 人类可读
    ```
  </Accordion>

  <Accordion title="cd (change directory) / pwd (print working directory) — 切换与查看目录">
    ```bash
    cd /etc           # 切换到指定目录
    cd ~              # 切换到当前用户家目录
    cd -              # 切换到上一次所在目录
    cd ..             # 返回上级目录
    pwd               # 显示当前所在目录的绝对路径
    ```
  </Accordion>

  <Accordion title="mkdir (make directory) / rmdir (remove directory) — 创建与删除目录">
    ```bash
    mkdir docs        # 创建单个目录
    mkdir -p a/b/c    # -p = --parents，递归创建多级目录
    rmdir empty_dir   # 仅可删除空目录
    ```
  </Accordion>

  <Accordion title="cp (copy) / mv (move) / rm (remove) — 复制、移动、删除">
    ```bash
    cp file1 file2    # 复制文件
    cp -r dir1 dir2   # -r = --recursive，递归复制目录
    cp -a src dst     # -a = --archive，保留权限和软链接
    mv old new        # 重命名或移动文件
    rm file           # 删除文件
    rm -r dir         # -r = --recursive，递归删除目录
    rm -rf dir        # -f = --force，强制递归删除（慎用）
    ```
    <Warning>
      `rm -rf` 不可恢复，执行前务必确认路径，避免误删系统目录。
    </Warning>
  </Accordion>

  <Accordion title="ln (link) — 创建链接">
    ```bash
    ln source hardlink              # 创建硬链接
    ln -s /path/to/file symlink     # -s = --symbolic，创建符号链接（软链接）
    ```
  </Accordion>

  <Accordion title="find / locate — 文件查找">
    ```bash
    find . -name "*.log"                  # -name 按文件名查找
    find /var -size +100M                 # -size 按文件大小查找
    find . -mtime -7                      # -mtime = modification time，7 天内修改过的
    find . -type f -name "*.tmp" -delete  # -type f 仅文件，找到即删除
    locate filename                       # 通过数据库快速定位（需先 updatedb）
    ```
  </Accordion>
</AccordionGroup>

# 2. 文件查看与编辑

<AccordionGroup>
  <Accordion title="cat (concatenate) / less / head / tail — 文件查看">
    ```bash
    cat file              # 输出整个文件
    less file             # 分页查看（支持 ↑↓ 翻页、/ 搜索）
    head -n 20 file       # -n = --lines，查看前 20 行
    tail -n 20 file       # 查看后 20 行
    tail -f app.log       # -f = --follow，实时跟踪日志变化
    ```
  </Accordion>

  <Accordion title="grep (global regular expression print) — 文本搜索">
    ```bash
    grep "error" log.txt              # 搜索包含 error 的行
    grep -i "error" log.txt           # -i = --ignore-case，忽略大小写
    grep -r "TODO" ./src              # -r = --recursive，目录中递归搜索
    grep -n "main" file.py            # -n = --line-number，显示行号
    grep -v "DEBUG" log.txt           # -v = --invert-match，反向匹配（不包含）
    grep -E "warn|error" log.txt      # -E = --extended-regexp，扩展正则
    ```
  </Accordion>

  <Accordion title="sed (stream editor) / awk — 文本处理">
    ```bash
    sed -n '10,20p' file              # -n = --quiet，仅打印 10-20 行
    sed -i 's/old/new/g' file         # -i = --in-place，原地替换
    awk '{print $1}' file             # 输出第一列
    awk -F',' '{print $2}' csv        # -F 指定 Field 分隔符
    awk '$3 > 100 {print $0}' file    # 第三列大于 100 的行
    ```
    <Tip>
      `awk` 命名来自三位作者 **A**ho、**W**einberger、**K**ernighan 的姓氏首字母。
    </Tip>
  </Accordion>
</AccordionGroup>

# 3. 文件权限与所有者

<AccordionGroup>
  <Accordion title="chmod (change mode) — 修改权限">
    ```bash
    chmod 755 script.sh          # 数字模式：rwx r-x r-x
    chmod +x script.sh           # +x 添加可执行权限
    chmod -R 644 ./docs          # -R = --recursive，递归修改
    chmod u+x,g-w file           # u=user 加执行；g=group 去写
    ```

    **权限位说明**

    | 数字 | 字母 | 全称 | 含义 |
    | --- | --- | --- | --- |
    | 4 | r | read | 读 |
    | 2 | w | write | 写 |
    | 1 | x | execute | 执行 |
    | 7 | rwx | - | 读写执行 |
    | 6 | rw- | - | 读写 |
    | 5 | r-x | - | 读和执行 |

    **角色字母**

    | 字母 | 全称 | 含义 |
    | --- | --- | --- |
    | u | user | 文件所有者 |
    | g | group | 所属组 |
    | o | others | 其他用户 |
    | a | all | 所有人（u+g+o） |
  </Accordion>

  <Accordion title="chown (change owner) / chgrp (change group) — 修改所有者">
    ```bash
    chown user file              # 修改文件所有者
    chown user:group file        # 同时修改用户和组
    chown -R www:www /var/www    # -R = --recursive，递归修改
    chgrp developers file        # 仅修改所属组
    ```
  </Accordion>
</AccordionGroup>

# 4. 进程管理

<AccordionGroup>
  <Accordion title="ps (process status) / top / htop — 查看进程">
    ```bash
    ps aux                       # a=all w/ tty, u=user format, x=含无 tty 进程
    ps -ef | grep nginx          # -e=every (all), -f=full format
    top                          # 实时进程监控（table of processes）
    htop                         # h=human，增强版交互式进程监控
    ```
  </Accordion>

  <Accordion title="kill / killall / pkill — 结束进程">
    ```bash
    kill 1234                    # 默认发送 SIGTERM (15) 给 PID 1234
    kill -9 1234                 # -9 = SIGKILL，强制结束
    killall nginx                # 按名称结束所有同名进程
    pkill -f "python script.py"  # -f = --full，按完整命令行匹配
    ```

    **常用信号**

    | 信号 | 编号 | 含义 |
    | --- | --- | --- |
    | SIGHUP | 1 | 挂起（重读配置） |
    | SIGINT | 2 | 中断（等同 Ctrl+C） |
    | SIGTERM | 15 | 优雅终止 |
    | SIGKILL | 9 | 强制结束（不可被捕获） |
  </Accordion>

  <Accordion title="jobs / bg / fg / nohup — 后台任务">
    ```bash
    command &                    # & 后台运行
    jobs                         # 查看后台任务列表
    fg %1                        # fg=foreground，把任务 1 切回前台
    bg %1                        # bg=background，任务 1 转后台运行
    nohup ./run.sh &             # nohup = no hangup，退出登录后仍持续运行
    ```
  </Accordion>
</AccordionGroup>

# 5. 网络命令

<AccordionGroup>
  <Accordion title="curl (Client for URLs) / wget (web get) — HTTP 请求与下载">
    ```bash
    curl https://example.com                          # 默认 GET 请求
    curl -X POST -d "name=foo" https://api.com        # -X = --request, -d = --data
    curl -H "Authorization: Bearer xxx" url           # -H = --header，添加请求头
    curl -o file.zip https://example.com/file.zip     # -o = --output，保存到文件
    curl -I https://example.com                       # -I = --head，仅取响应头
    wget https://example.com/file.zip                 # 下载文件
    wget -c url                                       # -c = --continue，断点续传
    ```
  </Accordion>

  <Accordion title="ping / traceroute / dig (domain information groper) — 网络诊断">
    ```bash
    ping baidu.com                                    # 测试连通性
    ping -c 4 baidu.com                               # -c = count，仅发送 4 个包
    traceroute baidu.com                              # 追踪路由路径（trace + route）
    dig example.com                                   # DNS 查询（推荐）
    nslookup example.com                              # name server lookup（旧）
    ```
  </Accordion>

  <Accordion title="netstat (network statistics) / ss (socket statistics) / lsof (list open files) — 端口与连接">
    ```bash
    netstat -tulpn        # -t=tcp, -u=udp, -l=listening, -p=program, -n=numeric
    ss -tulpn             # ss 是 netstat 的现代替代品，参数同义
    ss -anp | grep :80    # -a=all, -n=numeric, -p=process
    lsof -i :3000         # -i = internet，查看占用 3000 端口的进程
    lsof -p 1234          # -p = pid，查看 PID 打开的所有文件
    ```
  </Accordion>
</AccordionGroup>

# 6. 系统信息

<AccordionGroup>
  <Accordion title="uname (unix name) / uptime / who — 基本信息">
    ```bash
    uname -a                     # -a = --all，内核与系统全部信息
    hostname                     # 主机名
    uptime                       # up time，运行时长与负载
    who                          # 当前登录用户
    w                            # 用户及其进程
    last                         # 最近登录历史
    ```
  </Accordion>

  <Accordion title="df (disk free) / du (disk usage) / free — 磁盘与内存">
    ```bash
    df -h                        # -h = --human-readable，磁盘使用情况
    du -sh ./*                   # -s = --summarize, -h = --human-readable
    du -sh /var/log              # 指定目录大小
    free -h                      # -h = --human，内存使用情况
    free -m                      # -m = --mega，以 MB 显示
    ```
  </Accordion>

  <Accordion title="date / cal (calendar) — 时间">
    ```bash
    date                                         # 当前时间
    date "+%Y-%m-%d %H:%M:%S"                    # 自定义格式
    date -d "yesterday" "+%Y-%m-%d"              # -d = --date，计算昨天
    cal                                          # 当月日历
    cal 2026                                     # 整年日历
    ```
  </Accordion>
</AccordionGroup>

# 7. 用户管理

<AccordionGroup>
  <Accordion title="useradd / userdel / passwd / usermod — 账号管理">
    ```bash
    useradd -m -s /bin/bash alice    # -m = --create-home, -s = --shell
    passwd alice                     # password，修改密码
    userdel -r alice                 # -r = --remove，删除用户及家目录
    usermod -aG sudo alice           # -a = --append, -G = --groups，加入 sudo 组
    groups alice                     # 查看用户所属组
    ```
  </Accordion>

  <Accordion title="su (substitute user) / sudo (superuser do) — 切换权限">
    ```bash
    su - root                        # - 表示加载目标用户登录环境
    sudo command                     # 以 root 执行单条命令
    sudo -i                          # -i = --login，进入 root 交互 shell
    sudo -u alice command            # -u = --user，以指定用户执行
    ```
  </Accordion>
</AccordionGroup>

# 9. 压缩与解压

<AccordionGroup>
  <Accordion title="tar (tape archive) — 归档">
    ```bash
    tar -cvf archive.tar dir/        # 打包（不压缩）
    tar -xvf archive.tar             # 解包
    tar -czvf archive.tar.gz dir/    # 打包并 gzip 压缩
    tar -xzvf archive.tar.gz         # 解压 .tar.gz
    tar -cjvf archive.tar.bz2 dir/   # 打包并 bzip2 压缩
    tar -xjvf archive.tar.bz2        # 解压 .tar.bz2
    tar -tf archive.tar              # 查看归档内容
    ```

    **参数全称速查**

    | 参数 | 全称 | 含义 |
    | --- | --- | --- |
    | `-c` | `--create` | 创建归档 |
    | `-x` | `--extract` | 解压归档 |
    | `-t` | `--list` | 查看内容 |
    | `-v` | `--verbose` | 显示详细过程 |
    | `-f` | `--file` | 指定文件名 |
    | `-z` | `--gzip` | 用 gzip 压缩/解压 |
    | `-j` | `--bzip2` | 用 bzip2 压缩/解压 |
    | `-J` | `--xz` | 用 xz 压缩/解压 |
  </Accordion>

  <Accordion title="zip / unzip — ZIP 压缩">
    ```bash
    zip -r archive.zip dir/          # -r = --recurse-paths，递归压缩目录
    unzip archive.zip                # 解压到当前目录
    unzip archive.zip -d /tmp/       # -d = --directory，解压到指定目录
    unzip -l archive.zip             # -l = --list，仅列出内容
    ```
  </Accordion>
</AccordionGroup>

# 10. 输入输出与管道

<AccordionGroup>
  <Accordion title="重定向 (Redirection)">
    ```bash
    command > file              # 标准输出（stdout, fd 1）覆盖写入
    command >> file             # 标准输出追加写入
    command 2> error.log        # 标准错误（stderr, fd 2）重定向
    command > out 2>&1          # stdout 和 stderr 都写入 out
    command &> all.log          # 同上简写（bash）
    command < input.txt         # 标准输入（stdin, fd 0）从文件读取
    ```

    **文件描述符**

    | fd | 名称 | 全称 |
    | --- | --- | --- |
    | 0 | stdin | standard input |
    | 1 | stdout | standard output |
    | 2 | stderr | standard error |
  </Accordion>

  <Accordion title="管道 (Pipe) 与 xargs (extended arguments)">
    ```bash
    cat file | grep error | wc -l            # wc=word count，统计 error 行数
    ps aux | grep nginx | awk '{print $2}'   # 提取 nginx 进程 PID
    find . -name "*.log" | xargs rm          # 查找并批量删除
    ls *.txt | xargs -I {} mv {} {}.bak      # -I 指定占位符，批量重命名
    ```
  </Accordion>
</AccordionGroup>

# 11. 实用技巧

<CardGroup cols={2}>
  <Card title="快捷键">
    - `Ctrl + C` 中断当前命令（cancel）
    - `Ctrl + D` 退出当前 shell（EOF）
    - `Ctrl + L` 清屏（等同 `clear`）
    - `Ctrl + R` reverse-search 历史命令
    - `Ctrl + A / E` 跳到行首 / 行尾
    - `Ctrl + U / K` 删除光标前 / 后所有内容
    - `!!` 重复上一条命令
    - `!$` 上条命令的最后一个参数
  </Card>
  <Card title="历史与帮助">
    - `history` 查看历史命令
    - `history | grep ssh` 搜索历史
    - `man command` manual，查看手册
    - `command --help` 简略帮助
    - `tldr command` too long; didn't read，简化示例
    - `which command` 命令所在路径
    - `type command` 命令类型（别名/函数/可执行）
  </Card>
</CardGroup>
